# Getting help

CodeSense has a single maintainer.

- **Bugs:** open an issue on
  [GitHub](https://github.com/codesensehq/codesense/issues). Say what you did,
  what you expected and what happened, with your macOS and CodeSense versions.
  Search the open issues first. We read issues as time allows.
- **Questions and ideas:** start a
  [GitHub Discussion](https://github.com/codesensehq/codesense/discussions).
- **Security problems:** don't open an issue. Email
  [security@codesense.ai](mailto:security@codesense.ai), as described in
  [SECURITY.md](SECURITY.md).
- **Conduct problems:** email [conduct@codesense.ai](mailto:conduct@codesense.ai)
  (see the [Code of Conduct](CODE_OF_CONDUCT.md)).
- **Contributing:** we don't accept pull requests yet; see
  [CONTRIBUTING.md](CONTRIBUTING.md).

There is no paid support.
