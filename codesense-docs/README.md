# CodeSense

This is the CodeSense docs context repo. Every CodeSense install includes it, so you can learn
CodeSense by opening it in CodeSense.

Start with [getting-started/content/README.html](getting-started/content/README.html).

It's read-only in CodeSense. To get updates, ask your agent to run the `update-codesense-docs`
skill: it checks docs versions with `codesense_overview`, then uses `update_codesense_docs`
to select this running app's bundled version offline. Local work is preserved on a named
branch before replacement; no network or private remote is needed.
