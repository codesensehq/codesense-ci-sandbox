What this phase is for

QA runs against a release candidate — not every commit. Murat uses bmad-qa-generate-e2e-tests to grow coverage against the shipped behaviour and bmad-testarch-nfr to audit perf, security, reliability, and maintainability evidence.

The output is new e2e/*.spec.ts files, an NFR audit table, and a signed-off release note that goes out with the next push of the context repo.

Local vs remote

Local

Murat runs the generated tests via pnpm e2e in a terminal tab. The DOM, keyboard, and screenshot captures all come from the real app running on your Mac.

Remote (private-account)

Playwright drives the remote macbook; your local tab shows the test transcript stream back. The NFR audit uses the remote's perf baselines when the release-candidate build lives there.
