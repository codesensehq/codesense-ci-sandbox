Arc H 14 phases pipelines + SDLC

From the itch to the ship

This arc shows one way to run the whole software development life cycle with agents in CodeSense: an idea becomes a spec, becomes an architecture, becomes stories, becomes pull requests, becomes a release. Each phase is one agent, one skill, one inbox role, one trigger, one dashboard. The agents do the work; CodeSense gives them the files, worktrees, inbox and tools. This arc walks every phase with the same seeded example so you can lift the shape into your own repo.

What this arc covers

There are 14 phases in the CodeSense SDLC. The first seven are planning and design; phases 8–12 are build + verify; 13 and 14 are ship and loop. The agents are named: Mary analyses, Winston designs, Sally draws, John plans, Murat tests, Amelia builds, Resolver decides. Every page in this arc tells one phase's story with a worked example from the seeded DEMO epic.

The skills named here (bmad-create-epics-and-stories and the rest) come from BMAD, which you install in your own repo; CodeSense doesn't ship them. The phases are a pattern, not a gate: a story's status: is a plain field, nothing in CodeSense blocks a move between statuses, and each team sets its own statuses in Settings › Phases.

You should read this arc end to end once, then come back when you need the detail for a specific phase. The live factory playbook dashboard shows the state of your own repo through the same lens.

How to use this arc

Read it top to bottom

Start with phase 1 — idea and click through. Each page is a 5-minute read; the whole arc is a lunchtime.

Jump to a phase you own

A PM looking for sprint-planning mechanics should start at phase 6; a builder should start at phase 8 and loop back for context.

Copy the agent + routine snippets

Every phase shows a starting agent.yaml and, where the phase runs on a trigger, a routine.yml. Check them against the schemas below before you save them; an invalid agent.yaml refuses to load.

Watch the dashboard breathe

Keep factory playbook open in a split pane while you read; the content explains the model, the dashboard shows the state.

One worked example, all the way through

Every phase page uses the same seeded DEMO epic as its example: "one-click kill from the DAG please." It's a 5-story epic Mary wrote in response to a human's inbox note, Winston designed, John sliced, Amelia built in parallel worktrees, Winston reviewed, Murat QA'd, Amelia shipped. The epic lives at examples/sample-epic/ in this very repo — read the stories now if you want to see what each phase's output looked like end-to-end.
