What this phase is for

An architecture is a spine: the invariants that survive refactors, the shape every downstream artifact projects out of. Winston runs bmad-architecture against the spec from phase 2 and ships one short doc + at most one diagram per surface.

The output is deliberately thin. If your architecture doc lists every file in the repo, you wrote inventory, not architecture.

Local vs remote

Local

Winston uses apply_canvas and render_canvas to author Excalidraw diagrams and render their PNG sidecars right next to the architecture doc. The resulting .excalidraw file is clickable in-app.

Remote (private-account)

Same two MCP tools — the canvas state round-trips through the remote host agent. Opening the .excalidraw tab shows the live canvas backed by the remote file.

Try this now

Run bmad-architecture against your most recent spec. Winston will produce the spine and a sibling Excalidraw diagram.

How to do this via MCP 
codesense.invoke('runSkill', { skill: 'bmad-architecture' })
codesense.invoke('apply_canvas', { path: 'diagrams/kill-ladder.excalidraw', elements: [...] })
