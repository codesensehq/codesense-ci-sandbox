Phase 09 · Decisions

When a builder hits an ambiguity that can't be resolved from the spec alone, it escalates to the Resolver inbox. bmad-loop-resolve is the structured escalation skill — frozen spec in, decision out, builder resumes.

Agent… Skill… Inbox… Trigger… Dashboard…

What this phase is for

The best builder knows when to stop. If Amelia can't decide between two reasonable paths from the spec alone, she stops, escalates, and sleeps. bmad-loop-resolve wraps the escalation: it freezes the current spec state, posts a decision request to the resolver inbox, and resumes the builder when the answer lands.

The resolver is often a human. On well-trodden paths, it's an agent (Winston or Mary) running the same skill with a wider context budget.

Local vs remote

Local

The agent-inbox-console.html dashboard shows the resolver inbox in the top-right of the window. A badge pulses when a builder escalates; one click opens the escalation.

Remote (private-account)

The resolver inbox is per-team, not per-machine. A remote Amelia and a local Amelia share the same resolver queue, and your decision lands on both.
