Arc C · Workspaces & worktrees

A workspace per thing you're doing.

Every piece of work in CodeSense opens into its own workspace: a story, an epic, a team, or a plain working dir. The ones that need code get a real git worktree on disk — created on first open, given the context its agent declares when the agent launches, isolated enough to run five of them side by side. CodeSense never commits, pushes or merges; your agents do.

Why workspaces exist

You've got five feature branches, two decisions outstanding, and an epic you're actively refining. You want one of each on screen without them tripping on each other's working tree. CodeSense gives every unit of work its own workspace: story workspaces open against a git worktree; epic workspaces hold the surrounding plan; team workspaces are the whole team view; a generic workspace is a plain dir. Agents open workspaces the same way people do, through the same open_workspace MCP tool, so the dashboards and the automation see the same thing you do.

Primitives in play

The MCP tools and worktree.yaml schema this arc touches.

Primitives in play

  • open_workspace — launch any workspace. Takes a target (story id, team name, dir handle) and settles with opened, alreadyLive, busy, or invalid.
  • list_worktrees — every managed worktree on this Mac, with its story id, branch, path, machine, and last check-in.
  • hydrate_worktree / hydrate_story — copy team content into a worktree when an agent asks: exact paths or folders, or a story's epic.
  • read_worktree_config / write_worktree_config — the worktree.yaml schema seat: setup commands, env, timeouts, branch prefix.
  • list_hydrated — what's currently hydrated into a given worktree.

Live schemas: open_workspace · list_worktrees · hydrate_worktree · worktree.yaml schema.

How to do this via MCP

Agent-side equivalent

Every page in this arc is reproducible from an agent through MCP, no UI required. A warm-up tour: 

codesense.invoke('list_worktrees', {})
codesense.invoke('open_workspace', { target: 'DEMO-1' })
codesense.invoke('read_worktree_config', { source_repo: 'acme/sample-source-repo' })
