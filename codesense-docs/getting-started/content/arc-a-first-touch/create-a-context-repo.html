Create a context repo

You don't have one yet. Make one: CodeSense creates a new folder, starts a git repo in it, writes the few files a context repo needs, and switches to it. You or your agents run git from there; CodeSense never commits or pushes.

Start from the CodeSense example

The form's Start from the CodeSense example option is off by default. Turn it on and the new repo starts as an editable copy of these docs: the agents, routines, examples and dashboards you can open here, in a form you can change. Leave it off and the repo starts empty. Either way the read-only CodeSense Docs stay one switch away to compare against.

Create one in three steps

1

Open the create form

Open the context repo menu: the context repo / team name at the top left, or ⌘⇧G. At the bottom of its context repos, choose Create a new context repo….

2

Name it, then Create and connect

Type a Name. The Location follows it as ~/CodeSense/<name> until you type another path or use Choose…. The folder must not exist yet: CodeSense never writes into an existing folder. Choose Create and connect.

The new folder holds org.yml, people.yml and teams.yml and a git repo on an unborn main: no commit, no remote, no author set. The repo's id comes from the name (Acme Billing becomes acme-billing); a name already in use is refused.

3

You land in the new repo

CodeSense switches to it. A new, empty repo has no teams yet, so it asks you to Create a team. From now on CodeSense opens the context repo you used last, and the menu lists it next to the CodeSense Docs.

If the folder was created but couldn't be connected, the error names the folder. Use Connect a context repo… with it to retry.

How to do this via MCP

Agent-side equivalent

A local agent can create one, then add its first team, with the same services the app uses. destinationPath is an absolute new folder. The MCP tool has no example option: it always starts empty. 

create_local_organization({
  displayName: "Acme Billing",
  destinationPath: "/Users/you/CodeSense/acme-billing",
})
commit_registry_edit_local({
  orgSlug: "acme-billing",
  edit: { type: "CreateTeam", team_name: "billing" },
})
