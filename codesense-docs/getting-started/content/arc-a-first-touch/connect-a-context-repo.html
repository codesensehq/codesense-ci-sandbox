Connect a context repo

Your team already has a context repo, or you made one on another Mac. Clone it with git, then point CodeSense at the folder. CodeSense records where it is, switches to it and starts watching its files. It doesn't move, copy or clone anything, and it won't commit, push or merge there: you or your agents do.

When to pick this path

Connect when any of these is true:

  • Someone on your team already shares a context repo over git.
  • You copied the CodeSense example into your own repo and pushed it.
  • You moved a context repo to a new Mac and want CodeSense to see it.

If none of these apply, create a context repo instead.

Connect it in three steps

1

Clone it, then open the menu

Clone the repo with git, or ask your agent to. Then open the context repo menu: the context repo / team name at the top left, or ⌘⇧G. Choose Connect a context repo…. A folder picker opens.

2

Pick the clone's top folder

Pick the folder you cloned: the one with .git/ and org.yml at its top. CodeSense asks Connect {name}? and says it will read and write files there. Choose Connect, or Choose another folder.

3

CodeSense switches to it

CodeSense records the folder in ~/.codesense/users/<you>/context-attachments.yml and opens it. The menu lists it next to the CodeSense Docs, and from now on CodeSense opens the context repo you used last.

Not a context repo? A folder that isn't a git checkout's top folder, or has no valid org.yml, is refused: "This folder isn't a CodeSense context repo. Pick the folder you cloned, or create a new one." If another connected repo already uses the same id, the error says which org.yml to edit.

Moved it? A connected repo that's gone from its folder shows as missing. Locate the folder if you moved it, or disconnect it. Disconnecting only forgets the folder; every file stays.

How to do this via MCP

Agent-side equivalent

A local agent can connect a clone, list what's connected and switch team without the UI: 

attach_context_repository({ clonePath: "/Users/you/code/acme-context" })
list_context_attachments({})
list_orgs_teams()
set_active_team({ org: "acme-billing", team: "billing" })
detach_context_repository({ orgSlug: "acme-billing" })  // forgets it; files stay
