Agent-side equivalent

Every step in this arc is reproducible from an agent through MCP — no UI required. For the first-launch primer: 

list_orgs_teams {}
create_local_organization { displayName: "Acme", destinationPath: "/Users/you/CodeSense/acme" }
commit_registry_edit_local { orgSlug: "acme", edit: { type: "CreateTeam", team_name: "billing" } }
set_active_team { org: "acme", team: "billing" }
