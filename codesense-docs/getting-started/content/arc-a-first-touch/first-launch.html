First launch

You double-clicked the app. CodeSense opens, lays down a small home directory for itself, and lands you right here — on these docs. There's nothing to configure yet; the only decision in your first minute is whether you already have a context repo on disk or want to make a new one.

What happens on first open

1

CodeSense claims a home directory

The app creates ~/.codesense/ if it doesn't exist. That's where it keeps everything of its own: managed binaries, the MCP socket, state files, caches. In your source repos it adds worktrees when you open a story and writes a marked block in the repo's .git/info/exclude; it never commits or pushes, and git is yours lists every git command it runs. (The full tree is on files on disk.)

2

You land in the docs org

CodeSense pins one context repo for you: the shipped docs org — the read-only training manual you're reading right now. The book icon at the top-left is pinned here forever. One click re-opens these pages from anywhere in the app.

3

Everything else is still empty

You have no editable context repo yet. The Try this now buttons across these docs will prompt you to make one the first time you click. You can take the 60-second tour, read on, or jump to connecting a repo you already have or creating one from scratch.
