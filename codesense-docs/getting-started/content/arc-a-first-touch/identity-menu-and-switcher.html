Identity menu & switcher

The top-left of every CodeSense window carries one little menu — your name, the active org, and the active team. It's the only place you need to go to switch between a repo you're reading and one you're editing. One keystroke (⌘⇧G) opens it focused on the switcher.

The menu answers three questions at once: who you are, which org you're reading, and which team of that org is active. Every CodeSense action — opening a file, running a routine, writing a story — honours the active row.

Three moves you'll make here

1

Open it

Click the trigger (your name + the current team) in the top-left — right after the macOS traffic lights. Or press ⌘⇧G — the menu opens focused on the Orgs section, which is the one you want 90% of the time.

⌘⇧G — open with Orgs focused · ⌘⌥⇧T — open with Teams focused
2

Switch active org or team

Click any row to make it active. The window reloads and every pane re-anchors — the file tree, open tabs, the identity trigger itself. Nothing you had unsaved is lost; CodeSense persists tab state per org.

3

Reach for Create / Connect from here too

The same menu holds Create a new context repo… and Connect an existing context repo…. These are the two paths you took to get here — now they're one click away forever, no matter where you are in the app.

Tool reference

Reference for the three tools an agent can call to see where it is, read the overview of CodeSense right now and refresh the bundled docs.

Orientation

who_am_i

Reports who you are in CodeSense: your own list_sessions row, {handle, sessionId, displayName, machine, machineId?, workspaceHandle?, workspace, story?, role?, avatar?, agent?, launchedBy, state}. session_id is optional: omitted, it is the tab the connection runs in; pass your $CODESENSE_TAB_SESSION_ID to name a session. displayName is your tab's current name, which your inbox messages show as; rename yourself with rename_terminal_tab. handle is how others address you. machineId is present for a remote tab only. It errors when the session is not running.

{
  "tool": "who_am_i",
  "arguments": {
    "session_id": "<your $CODESENSE_TAB_SESSION_ID>"
  }
}

codesense_overview

Gives an overview of CodeSense right now in one read-only call: {generatedAt, context, machines, sessions, agents, routines, inbox, roleQueues, workspaces, docs}. Each section has detail, the tools to call for the full data, and a section that could not be read has error instead of data. Lists are capped (truncated: true). With guide: true it returns the concepts guide instead.

{
  "tool": "codesense_overview",
  "arguments": {
    "guide": true
  }
}

update_codesense_docs

Updates the canonical profile's CodeSense docs to this app's bundled version, offline and independently of the caller's working directory. The replacement preserves local HEAD and history, staged content, tracked edits and non-ignored untracked files on a named local branch before checkout; ignored machine state stays in place and collisions are refused. A current clean copy is a no-op. No network or remote is used. Returns docs versions and state, root, preservationBranch and changedPaths.

{
  "tool": "update_codesense_docs",
  "arguments": {}
}
