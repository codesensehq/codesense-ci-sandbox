Create your first editable context repo

You landed in the docs org, the read-only docs CodeSense ships with. Anything that writes needs a context repo of your own. Pages can't create one for you; you make it from the context repo menu.

Create one now

  1. Open the context repo menu: the context repo / team name at the top left, or ⌘⇧G.
  2. Choose Create a new context repo…, type a Name, and turn on Start from the CodeSense example if you want an editable copy of these docs. Choose Create and connect.
  3. CodeSense switches to the new repo. Already have one? Use Connect a context repo… instead.

The full walk-through is Create a context repo.

How to do this via MCP

A local agent can create one with create_local_organization. It has no example option: the repo starts empty. 

create_local_organization {
  displayName: "Acme Billing",
  destinationPath: "/Users/you/CodeSense/acme-billing",
}
