Lifecycle and liveness

A frame can be loaded without being live. Render a useful initial state, install handlers, then explicitly signal readiness.

Readiness and first paint

Render a useful initial state, install handlers, then call codesense.ready(). An admitted subscribe() also marks the frame live, before its initial snapshot resolves, so install handlers before either call. Subscribe-only panes can be live too; a shim handshake or a successful fetch alone does not signal liveness. If neither readiness nor subscription admission arrives within 30 seconds, the slot falls back. This is one absolute deadline from the document attempt start; load events and renders do not restart it. While starting, the host shows a themed skeleton (or retains the previous working view during recovery), with host menus available; an uncaught startup failure can fall back sooner. Do not wait for a network request before rendering loading, empty and error states. Shipped examples require an explicit readiness call in static lint; only a runtime check proves the page becomes live.

codesense.firstPaint is the page's own JSON data element when present, otherwise an injected LiveHub snapshot, otherwise null. Narrow the shape before using it and subscribe for subsequent snapshots and deltas. Do not assume its rows are fresh forever.

Saving a pane keeps its view

Saving a visible pane keeps its last working frame on screen. The host briefly blocks pointer input and edits without moving focus; Tab, Shift+Tab, Escape and app shortcuts stay available. It flushes pending edits and starts one replacement behind it. Source changes use a trailing 150 ms debounce; manual Reload is immediate. The replacement receives live data and becomes visible only when it signals readiness. There is no empty pane between versions. The outgoing frame retires after the swap paints, through the normal bounded flush and teardown path. The host preserves the document window’s scroll position; use the snapshot hook for inner scroll areas and other local UI state.

A broken save or an attempt that reaches its absolute 30 second deadline keeps the previous version and shows the fallback strip. The previous pane becomes interactive again. Correct the source and save again, or use Reload. Hidden panes defer source reloads until shown. Directory events refresh affected descendants, while team activation and dropped-event recovery reread retained pane sources through the live hub and preserve revisions when pane metadata is unchanged. Host-persisted ui:* view state already restores; use the optional snapshot for local view details such as a scroll offset or a draft. 

<input id="draft" aria-label="Draft">
<div id="scroll" style="height:100px;overflow:auto">
  <div style="height:800px">Scrollable view</div>
</div>
<script>
const draft = document.querySelector('#draft');
const scroll = document.querySelector('#scroll');
const stop = codesense.onBeforeReload(() => ({
  draft: draft.value,
  scroll: scroll.scrollTop
}));

async function start() {
  const saved = await codesense.reloadState();
  if (saved && typeof saved === 'object' && !Array.isArray(saved)) {
    if (typeof saved.draft === 'string') draft.value = saved.draft;
    if (typeof saved.scroll === 'number') scroll.scrollTop = saved.scroll;
  }
  codesense.ready();
}
start();
codesense.onTeardown(stop);
</script>

onBeforeReload(fn) installs the latest hook and returns an unsubscribe. Return JSON or a promise for JSON, at most 64 KB in UTF-8 and within 100 ms. Oversize, late or non-JSON results are dropped and logged with console.warn in the frame and a host log line. Snapshot capture never gates readiness or delays the swap. Keep persistent edits in your normal save/flush path. reloadState() returns a promise that resolves exactly once to that JSON or null; a cold load or missing hook resolves null promptly at the host handshake, without waiting for the 100 ms deadline. Await it before restoring the view and announcing readiness. It is a handoff for one reload, not a persistent state store.

Focus and Escape

cs.onFocusIn(() => document.getElementById('filter').focus());
cs.onFocusReturn(() => document.getElementById('filter').focus());
document.addEventListener('keydown', event => {
  if (event.key === 'Escape') {
    event.preventDefault();
    cs.focusOut().catch(showError);
  }
});

Keep a visible focus indicator. Give focus back with focusOut() when Escape closes your own interaction; focusTerminal() explicitly returns to the terminal. The host also forwards navigation chords. Do not trap Tab or swallow unrelated keys.

Flush before retirement

cs.onFlush(async () => {
  await savePendingEdits(); // resolve only after writes settle; keep failures visible
});
cs.onTeardown(() => releaseLocalResources());

The host asks for flush before a pane replacement reads its data, and before closing or moving a frame, with a bounded acknowledgement wait. Reload preparation also freezes and flushes the pane’s owned embedded message frames. A discarded replacement unfreezes that same group. Return a promise for pending work. A read-only page may use an empty flush handler; never claim an unsaved change succeeded just to acknowledge. Avoid timers and duplicate watchers.

Hidden and stale states

onVisibility tells you whether the frame is shown. LiveHub suppresses hidden deliveries, marks the view stale once and resyncs it when shown. Keep a cheap stale/loading cue; let subscribe(topic, {onChange}) apply the resumed full snapshot. The SDK handles revision gaps and team rebinding. Do not issue polling reads while hidden. Release a subscription with unsubscribe(topic, callback), and dispose local listeners on teardown.
