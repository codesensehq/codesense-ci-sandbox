Commands, chords and menus

Declare commands once, register handlers in the page, and let the host deliver chords, palette actions and native menus.

Declare and register

<meta name="codesense:commands" content='[{"id":"toggle-filter","label":"Toggle running sessions","scope":"slot-focused","defaultChord":"CmdOrCtrl+Alt+L","humanOnly":false}]'>
<script>
const cs = window.codesense;
cs.onCommand(command => {
  if (command.id === 'toggle-filter') toggleFilter();
});
cs.ready();
cs.commands.register(['toggle-filter']).catch(showError);
</script>

Install handlers before calling ready() or subscribe(). Registration activates only declared ids. Delivery is queued until explicit readiness or an admitted subscription marks the frame live. Subscription admission can release commands before its initial snapshot resolves; the shim's automatic transport handshake does not count. Each dispatch has a dispatchId and is delivered at most once.

Scope and rebinding

global commands are available globally, slot-visible requires a visible slot, and slot-focused requires focus in its slot for the keyboard shortcut. defaultChord is the initial binding, not a guarantee: reserved or conflicting shortcuts may be unbound. The person can rebind or clear it in Settings → Shortcuts. Use the generated declaration contract for accepted scopes and fields.

humanOnly:true permits the person's palette/chord and page command invocation but refuses agent command_run. For an agent-verifiable command, leave it false. Agents discover the full dashboard/command id with command_list and pass that exact id to command_run. The host reveals a hidden target before delivering. On a dock team rebind the SDK holds calls, adopts the new grant and resyncs topics; handle onSlotContext to drop your own old-team state.

Native row menus

const row = document.createElement('li');
row.dataset.codesenseRow = JSON.stringify({kind: 'agent', sessionId: session.id});
row.textContent = session.displayName;
// A right click asks the host for the native agent menu. Keep normal text selection.

data-codesense-row identifies a row to the native menu builder. Story/file paths are relative to the bound team's content root. Use the SDK's ContextMenuRow union for row shapes. Unknown or unresolved rows fall back to the dashboard menu. Text fields and selected text get native text menus first.

For a custom button menu call showMenu({anchorRect, anchorId, row, items}); anchorRect is the button's bounding rect and anchorId lets focus return to it. Page-local item ids return to your handler. The host owns builtin:reload-pane, builtin:open-as-tab, builtin:edit-source, builtin:stop, builtin:close-tab and builtin:set-role; use only actions applicable to that row or dashboard. Built-ins retain their native validation and confirmation. See the golden live sessions example for a native row menu without a copied implementation.

Peek at an agent's terminal

Ask the host for agent-quick-send to open a themed quick view beside an agent row. The host owns the frame, terminal and positioning above the workspace bar. Open tab opens the agent's CLI tab. A terminal already visible in the CLI stays there; the quick view offers Show in CLI instead. 

const button = document.querySelector('#peek');
button.addEventListener('click', () => {
  const { x, y, width, height } = button.getBoundingClientRect();
  window.codesense.showPopover({
    kind: 'agent-quick-send',
    anchorId: button.id,
    anchorRect: { x, y, width, height },
    row: { kind: 'agent', sessionId: session.sessionId }
  });
});

Typing goes straight to the agent's terminal. Escape inside it goes to the CLI; Escape on the header controls closes the quick view. ⌘W and Close return focus to the invoking button. An outside click closes it where the person clicked. The resize corner remembers the size and also accepts arrow keys.
