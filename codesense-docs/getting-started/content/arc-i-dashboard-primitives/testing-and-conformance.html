Testing and conformance for agents

Use the shipped tools and references to check a pane without a source checkout. Distinguish static checks, rendered evidence and a real application walk.

Checks available without source

  1. Read get_live_data_contract and the generated declarations, capabilities and slots.
  2. Call validate_live_data_doc {content, path} on the exact HTML. It validates slot/capability/command declarations and reports heuristic usage findings and what it checked. A valid result does not execute JavaScript, check server responses or prove liveness.
  3. Use pane_write, pane_open and pane_list. Use the returned absolute path with read_rendered_document {path, format:"text"} while the pane is visible. Closed, hidden and fallback panes return actionable errors; show or fix the pane before retrying.
  4. Discover the command with command_list, invoke its returned id using command_run, then capture again and compare visible feedback. The recipe shows the sequence.

Rendered evidence is bounded, point-in-time DOM content, not a screenshot or a freshness guarantee. The tool does not open a pane or run data collection for you. For a visual and keyboard walk ask the person to inspect the running pane; label unperformed in-app behavior unproven, not blocking.

Source-only conformance

Maintainers with a CodeSense source checkout run pnpm test:conformance -- path/to/pane.html. The existing WebKit harness mounts the real slot host, viewer and injected SDK with fixture data. It checks focus-in, Escape, flush, budget denial, hidden/stale/resync, maximize/restore, reparent and accessibility. This is separate from the agent-facing MCP checks above; user agents do not need the source.

The docs build statically checks every shipped dashboard example for executable explicit readiness, script syntax and declarations against generated contracts, and refuses the bundle on failure. It cannot prove the readiness call is reached at runtime. The golden example additionally runs against pushed rows and a declared command through the conformance host.
