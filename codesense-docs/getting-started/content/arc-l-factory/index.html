The factory, as a kit

Arc L is the capstone. The primitives you've met across the earlier arcs — worktrees, agents, inboxes, routines, dashboards — compose into a running agentic software factory. Massively parallel. Local, remote, or both. On your Mac tonight.

What this arc teaches

Six roles — Builder, Scout, Resolver, Reviewer, Triager, Analyst — compose into recipes you copy-paste into your own context repo and run. You pick a distribution shape (one Mac? home + remote mini? your whole team?) and dial up the number of agents until the inbox backs up or the DAG goes green. That's the factory.

Every page here cross-links to the live factory-playbook — Phase 8 (Build parallel), to the inbox flow kit, and to the recipes gallery. Nothing in Arc L is new primitive — it's new composition.

Primitives this arc leans on

  • Worktrees — one per story, isolated git checkouts. See concepts.
  • Agents — immutable identity + runtime + skills. See agent.yaml.
  • Inbox roles — builder, reviewer, resolver, scout, triager, analyst. Claim-and-ack serializes work.
  • Routines — a schedule, or an event (role_pending, inbox_idle, agent_done), starts or wakes agents without a human in the loop. See routine.yml.
  • Private-account mode — remote Macs under the same account cooperate without SSH gymnastics. See the concepts on remote execution.
  • agent-dag + pipeline-graph — the two factory monitors. See auditing.
