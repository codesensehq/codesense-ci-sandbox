Terminal server tools

Reference for the tools that inspect, start, stop, restart, update and replace terminal servers, on This Mac and on registered machines.

How to read this page

The terminal server hosts every terminal tab and agent, and outlives the app. Stopping or restarting one ends the terminals and agents it runs, so these tools bind to what you reviewed: pass expected back exactly as the status or listing tool returned it, and confirm explicitly. If anything changed since, the call is refused and nothing ends; read the status again.

This Mac

terminal_server_status

Reports This Mac's terminal server for this CodeSense instance: state (running, stopped, incompatible, unreachable or notApplicable), pid, version, session counts, ends (in words, what a stop or restart would end), connectedInstances, unowned sessions no app holds, and expected, what stop and restart bind to. It never starts a server.

{
  "tool": "terminal_server_status",
  "arguments": {}
}

start_terminal_server

Starts This Mac's terminal server when none runs, as opening a terminal does; a running one is only connected to. Returns the same fields as terminal_server_status.

{
  "tool": "start_terminal_server",
  "arguments": {}
}

stop_terminal_server

Stops This Mac's terminal server, ending every terminal and agent it runs, including other CodeSense instances' tabs. Nothing is started in its place. Requires confirmEndSessions: true and expected from terminal_server_status. Returns {ended, ends, otherInstances}.

{
  "tool": "stop_terminal_server",
  "arguments": {
    "confirmEndSessions": true,
    "expected": {
      "serverId": "<serverId from terminal_server_status>",
      "epoch": "<epoch from terminal_server_status>",
      "pid": 4242,
      "sessionIds": [
        "<session ids from terminal_server_status>"
      ],
      "otherInstances": 0
    }
  }
}

restart_terminal_server

Restarts This Mac's terminal server: the running one stops, ending its terminals and agents, and this build's starts in its place. Requires confirmEndSessions: true and expected; expected may be omitted only while the state is incompatible, where reviewedIncompatible {pid, sessions, otherInstances} guards against change. Returns {restarted:true, ended, ends, otherInstances}.

{
  "tool": "restart_terminal_server",
  "arguments": {
    "confirmEndSessions": true,
    "expected": {
      "serverId": "<serverId from terminal_server_status>",
      "epoch": "<epoch from terminal_server_status>",
      "pid": 4242,
      "sessionIds": [
        "<session ids from terminal_server_status>"
      ],
      "otherInstances": 0
    }
  }
}

end_unowned_terminal_session

Ends one session that no app holds: a leftover of a CodeSense instance that crashed or was force-quit, and whatever it runs. Take session from unowned in terminal_server_status. Requires confirmEndSession: true. It is refused, and nothing ends, if an app holds the session by then or it is gone.

{
  "tool": "end_unowned_terminal_session",
  "arguments": {
    "session": "<session from unowned>",
    "confirmEndSession": true
  }
}

Updating servers to this build

list_out_of_date_terminal_servers

Lists terminal servers older than this app: the list_machines rows whose terminalServer.relation is older, each with the live tabs an update ends, untabbedSessions, isCaller, and expected, what update_terminal_servers binds to, or unavailable with why it cannot be updated now. orgSlug is required.

{
  "tool": "list_out_of_date_terminal_servers",
  "arguments": {
    "orgSlug": "acme"
  }
}

update_terminal_servers

Updates terminal servers to this app's build, ending every terminal and agent each runs (tabs reopen; agents as shells unless their Agent has resumeAfterRestart). Requires orgSlug, confirmEndSessions: true, expected per machine exactly as the listing returned it (sessionIds included) and either machineIds or all: true. It is asynchronous: it returns {opId, machines, skipped} at once, and the outcome goes to the caller's inbox. Your own machine updates last, so your tab may end before any reply.

{
  "tool": "update_terminal_servers",
  "arguments": {
    "orgSlug": "acme",
    "confirmEndSessions": true,
    "machineIds": [
      "<machineId>"
    ],
    "expected": {
      "<machineId>": {
        "serverId": "<serverId>",
        "epoch": "<epoch>",
        "sessionIds": [
          "<session id>"
        ]
      }
    }
  }
}

Registered machines

install_terminal_server

Installs the bundled terminal server on a trusted machine. It uses no sudo and no arbitrary provisioner. input is the machine draft, as for save_machine; machineId is optional.

{
  "tool": "install_terminal_server",
  "arguments": {
    "input": {
      "label": "build-box-01",
      "host": "build-box-01.example.com",
      "port": 22,
      "username": "dev",
      "signIn": {
        "method": "agent"
      }
    }
  }
}

prepare_machine_terminal_server_replacement

Prepares a one-use restart token for a registered machine. It does not stop sessions. Confirming the restart later ends every terminal and agent running at shutdown, including sessions started after preparation.

{
  "tool": "prepare_machine_terminal_server_replacement",
  "arguments": {
    "machineId": "<machineId from list_machines>"
  }
}

restart_machine_terminal_server

Executes a prepared restart. Requires the one-use serverToken and confirmEndSessions: true. Returns {status:"replaced", count, restored?} or {status:"failed", oldStopped, count, repair}. restored lists tabs reopened on the new server; agents that ran there end and reopen as shells, except a saved Agent with resumeAfterRestart.

{
  "tool": "restart_machine_terminal_server",
  "arguments": {
    "machineId": "<machineId from list_machines>",
    "serverToken": "<token from prepare_machine_terminal_server_replacement>",
    "confirmEndSessions": true
  }
}
