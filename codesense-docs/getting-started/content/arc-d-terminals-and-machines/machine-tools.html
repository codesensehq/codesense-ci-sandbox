Machine tools

Reference for the tools that discover, test, save, connect and manage machine declarations: from list_ssh_sources to resolve_machine_identity.

How to read this page

For what a machine is and the kinds of machine, see the Machines page linked below. This page covers the tools. list_machines returns the machine ids these tools take as machineId.

Each entry gives what the tool does, how it differs from its neighbours, and one call using the wire names the server expects.

Discover and test

list_ssh_sources

Discovers SSH config hosts on this Mac and the agent's public identities. It never reads private-key bytes. Use it to find a host and a sign-in method before building a draft for test_machine_connection or save_machine.

{
  "tool": "list_ssh_sources",
  "arguments": {}
}

test_machine_connection

Tests an explicit machine draft without saving it. Observe the host fingerprint first, then pass trustedHostKeyFp explicitly only after trust is authorized. mode defaults to private-account, the only mode that opens terminal tabs. A saved legacy machine tested with private-account is converted in place (same id, host key and settings) before its private setup.

{
  "tool": "test_machine_connection",
  "arguments": {
    "input": {
      "label": "build-box-01",
      "host": "build-box-01.example.com",
      "port": 22,
      "username": "dev",
      "signIn": {
        "method": "agent"
      }
    }
  }
}

capture_machine_passphrase

Opens the secure local passphrase dialog for a keyPath. It returns only a credential reference or cancelled; no passphrase crosses MCP. The reference is what a keychainPassphrase sign-in carries in credentialRef.

{
  "tool": "capture_machine_passphrase",
  "arguments": {
    "keyPath": "~/.ssh/id_ed25519"
  }
}

Save, share and remove

save_machine

Saves a personal or team machine declaration using existing authorization. input is the draft, share is {kind:"personal"} or {kind:"team", orgSlug, team}, and connect validates setup (use connect_machine for actual runtime admission). mode defaults to private-account; saving a legacy machine with that mode converts it in place. Auto-connect stays off.

{
  "tool": "save_machine",
  "arguments": {
    "input": {
      "label": "build-box-01",
      "host": "build-box-01.example.com",
      "port": 22,
      "username": "dev",
      "signIn": {
        "method": "agent"
      }
    },
    "share": {
      "kind": "personal"
    },
    "connect": false
  }
}

unshare_machine

Moves an authorized shared declaration back to personal scope.

{
  "tool": "unshare_machine",
  "arguments": {
    "machineId": "<machineId from list_machines>"
  }
}

remove_machine

Removes an authorized machine declaration and its local binding.

{
  "tool": "remove_machine",
  "arguments": {
    "machineId": "<machineId from list_machines>"
  }
}

Connect and disconnect

connect_machine

Connects a saved machine through the connection manager and returns the real admission and setup status. Where save_machine only validates, this is the call that connects.

{
  "tool": "connect_machine",
  "arguments": {
    "machineId": "<machineId from list_machines>"
  }
}

retry_machine

Retries a saved machine's connection through its existing manager. It does not enroll or trust anything automatically.

{
  "tool": "retry_machine",
  "arguments": {
    "machineId": "<machineId from list_machines>"
  }
}

disconnect_machine

Disconnects the current app from a machine without killing its remote terminal processes.

{
  "tool": "disconnect_machine",
  "arguments": {
    "machineId": "<machineId from list_machines>"
  }
}

Per-profile settings

set_machine_auto_connect

Opts a personal machine into background reconnect, or turns it off. It does not grant trust or enrollment. The default is off.

{
  "tool": "set_machine_auto_connect",
  "arguments": {
    "machineId": "<machineId from list_machines>",
    "autoConnect": true
  }
}

set_machine_hidden

Sets the current profile's visibility preference for a machine.

{
  "tool": "set_machine_hidden",
  "arguments": {
    "machineId": "<machineId from list_machines>",
    "hidden": true
  }
}

set_machine_remote_mcp_control

Sets this desktop profile's permission for remote agents on a private machine to use CodeSense. The default is off, a remote caller cannot grant it, and enabling it is an explicit personal trust decision.

{
  "tool": "set_machine_remote_mcp_control",
  "arguments": {
    "machineId": "<machineId from list_machines>",
    "enabled": false
  }
}

Identity changes

resolve_machine_identity

Reports or keeps refusing a machine identity change. list_machines returns declaration.identityChange with the accepted and declared fingerprints and a revision to pass here. accept:false keeps refusing. accept:true is a human-only action: agents cannot confirm it and must ask the person to review and confirm in Machines.

{
  "tool": "resolve_machine_identity",
  "arguments": {
    "machineId": "<machineId from list_machines>",
    "revision": "<revision from declaration.identityChange>",
    "accept": false
  }
}
