Remote workspace tools

Reference for the tools that prepare a workspace on a private machine, bring its committed work back to this Mac, and move a workspace between machines.

Prepare, fetch and move

prepare_remote_workspace

Prepares an owned remote Git repository and worktree on a configured private machine. Every field is required: teamKey (written org:team), workspaceId, a structured sourceRepo, a UUID requestId, baseRef, branch, and absolute repoPath and worktreePath. It reuses the verified desktop checkout's committed objects and returns the exact pinned commit, an opaque handle and the cwd for open_remote_tab. A locally available ref is a local snapshot, not latest-provider assurance. Repeat the same immutable request after an unknown outcome; never delete or reset partial work. Context hydration is a separate operation.

{
  "tool": "prepare_remote_workspace",
  "arguments": {
    "machineId": "<machineId from list_machines>",
    "teamKey": "acme:engineering",
    "workspaceId": "<workspace id>",
    "sourceRepo": {
      "owner": "acme",
      "repo": "app"
    },
    "requestId": "6f1c2e0a-8f55-4a3e-9d57-0b6a1b0f6c11",
    "baseRef": "main",
    "branch": "feature/example",
    "repoPath": "/home/dev/repos/app",
    "worktreePath": "/home/dev/worktrees/app-example"
  }
}

remote_workspace_fetch

Brings the committed work of a workspace that lives on a machine into this Mac's local clone. Name it by machineId + workspaceHandle, or by storyId / workspaceId of an open workspace (add teamKey if several teams match). Commits arrive as refs/remotes/codesense-machine-<machineId>/<branch>; the local branch is created, or fast-forwarded only when safe. It never merges, rebases or force-updates a local branch, and uncommitted work stays on the machine. Pushing and pull requests stay with your own git or forge tools.

{
  "tool": "remote_workspace_fetch",
  "arguments": {
    "machineId": "<machineId from list_machines>",
    "workspaceHandle": "<workspaceHandle from the workspace record>"
  }
}

move_workspace

Moves a team's workspace to another machine. Give storyId and targetMachine (from list_machines, or local); local targets also need targetWorktreePath. It reports running agents, uncommitted paths and unpushed commits, and refuses until you choose explicitly: stopRunningAgents, carryUnpushed or discardUnpushed (not both), discardUncommitted. Machine-to-machine carry is refused; move through this Mac. A source that changed stays intact with cleanupPending:true. It does not relaunch agents.

{
  "tool": "move_workspace",
  "arguments": {
    "storyId": "DEMO-13",
    "targetMachine": "<machineId from list_machines>"
  }
}
