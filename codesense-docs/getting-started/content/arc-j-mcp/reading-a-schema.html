Hand it a name. Get the contract.

Search found a tool. Before you call it, you want to know what it takes. codesense_get_tool_schema hands back the full description plus the input JSON schema — the shape tools/list carries for it, which a host that loads schemas lazily hasn't shown the agent yet. Required fields, allowed values, nested objects, examples.

The contract

Input: { name: string }. The name you got from codesense_search_tools, or one you already know.

Returns: { name, description, inputSchema }. Three fields, every time. The description is the exact text the explorer shows; the inputSchema is the exact JSON schema the server will validate against when the tool runs.

Unknown name: you get back { status: "unknown", name } — nothing throws, nothing errors. A no-match on a typo is a plain answer, not an exception; your agent can retry a search without special-casing.

How to read the shape

1

Start at required

Everything in required you have to pass. Nothing else is strictly needed to make the call — defaults kick in. If required is empty, the tool takes {}.

2

Look at properties

Each key names a field. type narrows what you can pass — "string", "integer", "boolean", "object", "array". Nested objects have their own properties block the same shape. enum narrows to a fixed set (["foreground", "headless"]).

3

Watch for oneOf / anyOf

add_source_repo takes exactly one of url or path — a oneOf on required fields. Pass both and the server rejects it. The description usually says this out loud; the schema makes it provable.

4

Read the description for the reply shape

The input schema says what goes in. The reply shape lives in the description field as prose — CodeSense returns { status: "ok", data: {…} } on success and { status: "validation", message } on bad input, consistently across tools.

Worked example

Call:

codesense.invoke('codesense_get_tool_schema', {
  name: 'add_source_repo'
})

Reply (abridged for shape):

{
  "name": "add_source_repo",
  "description": "Add a source repo to a team. Pass `org` (owner/repo) and `team`, plus
    exactly one of `url` (a remote — https://…, git@…, host/owner/repo, or GitHub
    shorthand owner/repo — tracked on the team) or `path` (the absolute path of a
    folder on this machine, which is then bound as the repo's local clone) …
    Returns { status:\"ok\", data:{ owner, repo, provider, host, remoteKey,
    localPath, remoteName, remoteUrl } }; unknown or archived team returns
    { status:\"unauthorizedTeam\" }; a bad URL or folder, a duplicate, or invalid
    source identity returns { status:\"validation\", message }.",
  "inputSchema": {
    "type": "object",
    "required": ["org", "team"],
    "properties": {
      "org":  { "type": "string", "description": "Team's org handle." },
      "team": { "type": "string", "description": "Team slug." },
      "url":  { "type": "string", "description": "A remote URL or owner/repo shorthand." },
      "path": { "type": "string", "description": "Absolute path on this machine." }
    },
    "oneOf": [
      { "required": ["url"] },
      { "required": ["path"] }
    ]
  }
}

Reading it:

  • org and team are always needed.
  • Pass exactly one of url / path.
  • Reply shape (from the description): {status: "ok", data: {owner, repo, …}} on success, named error statuses on failure.

Edge: unknown name

codesense.invoke('codesense_get_tool_schema', { name: 'add-source-repo' })
// → { status: "unknown", name: "add-source-repo" }

Underscores, not hyphens. Nothing throws; you get a shape your agent can branch on and retry a search with.

Try this now

Fetch the schema for add_source_repo. Read-only; nothing writes. The "Try this" sheet pretty-prints the schema.

How to do this via MCP 
// Always pair with a search first — don't guess names.
const { tools } = await codesense.invoke('codesense_search_tools', {
  query: 'add source repo'
})
const schema = await codesense.invoke('codesense_get_tool_schema', {
  name: tools[0].name
})

// Unknown name is a plain reply, not a throw.
const r = await codesense.invoke('codesense_get_tool_schema', { name: 'nope' })
if (r.status === 'unknown') { /* retry search */ }
