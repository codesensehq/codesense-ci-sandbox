You might already be done

Agents CodeSense launches don't need setup. Every agent you start from a tab, from the agents panel, from a routine or from a remote CodeSense machine already has the bridge wired. Everything in this arc works out of the box.

This page is for agents you start yourself in your own terminal — your personal Claude Code, your Codex, or any other MCP client. Add CodeSense once and they get the same tools.

The short answer

If you just want the Claude Code command, here it is:

claude mcp add --scope user codesense -- "$HOME/.codesense/bin/codesense-bridge"

Then restart your claude session. The tools in this arc are now in your /mcp list. The full page covers Codex, scoping, and what to do if the bridge isn't there yet.

How it fits

Once the MCP is wired, your own agent follows the same funnel as any CodeSense-launched one: codesense_overview first, then search, then schema, then call. Same four meta-tools, same full tool list, same contracts. The agent doesn't need to know whether it's running inside CodeSense or in your personal shell.

Run who_am_i. If the bridge is reachable it comes back with your handle and the active team — proof the MCP is live. Read-only; nothing writes.

How to do this via MCP

The setup itself is a shell command — one of the only things in CodeSense that isn't an MCP call, because the agent has to exist to run MCP. Once set up, every tool in mcp-explorer is reachable from your own terminal. 

# Claude Code
claude mcp add --scope user codesense -- "$HOME/.codesense/bin/codesense-bridge"
