Every verb is a tool. Four help you find it.

CodeSense's MCP server has a few hundred tools: every verb the app has, for any agent, on this Mac or a machine. All of them are listed in tools/list, so any MCP client can see and call them. You don't need to memorise them. Start with codesense_overview, search for the verb you need, read its schema, call it.

Why discovery tools

Every registered tool is in tools/list, because strict clients (Claude Code, for one) can only call tools they see there. The list doesn't change during a session, so clients can cache it. With a few hundred tools, finding the right one by name is the hard part. The four discovery tools do that: orient, search, read the schema, call.

The four discovery tools

codesense_overview

The first call, read-only. Your active org and team, machines, running sessions, saved agents, routines, inbox and open workspaces, each with the tools to call for more.

codesense_search_tools

Searches tool names and descriptions (case-insensitive; several terms must all match). Name matches rank above description matches. Default 20 results, up to 100.

codesense_get_tool_schema

The full description and input JSON schema of one tool. Then call the tool by its name.

codesense_call_tool

Calls any tool by name with an arguments object, for a host that can't call a tool directly. Most agents never need it.

Make the first call. It's read-only. You'll see what CodeSense knows about your setup right now: your active org and team, machines, sessions, agents, routines, inbox and open workspaces.

How to do this via MCP

The whole arc, in four calls. Every tool here is in tools/list, so a host can call add_source_repo directly once it knows the name. 

// 1. Where am I?
codesense_overview {}

// 2. Find the verb I need.
codesense_search_tools { query: 'add source repo' }

// 3. Read the contract.
codesense_get_tool_schema { name: 'add_source_repo' }

// 4. Call it — directly if your host can, else via codesense_call_tool.
add_source_repo { org: 'acme/team-context', team: 'default', url: '…' }
