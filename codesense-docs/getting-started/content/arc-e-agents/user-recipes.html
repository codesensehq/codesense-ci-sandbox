Arc E teaches you how an agent is shaped. The recipes under Setting up agents are the shaped agents, already written, with the skill they need alongside them. Rather than re-print the YAML on this page and have two sources of truth, this page is a door — click through to the recipe you want.

What you can set up today

CodeSense setup agent

Walks you through workspace, teams, source repos, agents and routines. Checks what's done, shows what's left, and asks before every change. Safe to run again at any time.

describe_setup create_local_organization attach_context_repository agent_create routine_create

Machine setup agent

Gets a remote machine ready for CodeSense and adds teammates to it. Pinned host key, SSH posture, terminal-server install. Cross-link: arc D → setup machine.

save_machine test_machine_connection prepare_machine_terminal_server_replacement restart_machine_terminal_server

Build a manager agent

An agent that holds a manager role queue, triages incoming work, launches and tracks workers, and reports to you. CodeSense has no built-in controller — this recipe builds one from generic tools so you can see every piece and change it.

register_role claim_role_messages accept_role_message open_workspace list_sessions send_message

Two ways to follow a recipe

Each recipe page spells both out. The short version:

  • By hand. The recipe lists the files to copy and where they go. Copy them into your team, then push with git.
  • Ask an agent. These docs are plain files on your Mac under ~/.codesense/users/<profile>/codesense-docs/. Any agent you can launch can read them. Say: "Set up the CodeSense setup agent from the CodeSense docs, in my team." The agent reads the recipe, copies the skill into your team, and calls agent_preview + agent_create with the fields the recipe lists. Pushing stays yours — CodeSense never commits or pushes.

Before the first recipe

If you want to run these recipes from your own claude or codex outside the CodeSense app, start here:

Add the CodeSense MCP to your own agents

Connect Claude Code, Codex or another MCP client you run yourself outside CodeSense. Agents launched from CodeSense already have it, and so does a claude or codex you type in any CodeSense tab.

Try this now

List the agents the active team already has. Compare against the three recipes above — whichever one you don't see is the one to set up next.

How to do this via MCP 
// What agents are on this team right now?
codesense.invoke('agent_list', { scope: 'team' })

// Preview the recipe's agent.yaml before saving.
codesense.invoke('agent_preview', { name, runtime, launch, startup, defaultPrompt })

// Create it, team-scoped. Pass scope: "personal" + org for Only me.
codesense.invoke('agent_create', { name, runtime, startup, scope: 'team' })
