Moving between contexts

Reference for the tools that copy, move, route and remove content between contexts, track the explicit context operations, and read sync state.

How to read this page

A context is identified by a stable id such as personal:<org> or team:<org>:<team>; list_context_content returns the logicalName of each item. Copy and move run the same gate ladder as the app and return {status:"gate", reason, ...} naming the first unmet gate and its resolution, so a retry is deterministic.

Copy, move and remove

move_between_contexts

Moves a content item by logicalName from one context to another, in either direction. Gates run one at a time in fixed order: cross-org, then privacy, then collision. An unmet gate returns {status:"gate", reason} with its resolution (an explicit org, confirmMakeShared: true, or a collision policy of keep_both, replace or keep_mine). A move out of the private space writes the target before removing the source; if the source cannot be removed the outcome is movedSourceKept. Markdown moved into a team records shared_by, shared_from and shared_on. Returns {status:"ok", outcome, renamedTo?}.

{
  "tool": "move_between_contexts",
  "arguments": {
    "from": "personal:acme",
    "to": "team:acme:engineering",
    "logicalName": "notes/plan.md",
    "confirmMakeShared": true
  }
}

copy_between_contexts

The source-retaining sibling of move_between_contexts: the item is duplicated into the target and the source keeps it. Same gates, parameters and gate result. Copying between two orgs' private spaces (personal:<a> to personal:<b>) needs no org switch. Returns {status:"ok", outcome:"copied", renamedTo?}.

{
  "tool": "copy_between_contexts",
  "arguments": {
    "from": "personal:acme",
    "to": "team:acme:engineering",
    "logicalName": "notes/plan.md",
    "confirmMakeShared": true
  }
}

remove_from_context

Deletes a content item by logicalName from a single context. Removing a private item first returns {status:"gate", reason:"sole_copy"}, because the private space may hold the only copy; re-call with allowSoleCopyMove: true to delete permanently. Removing an item that is already gone returns {status:"ok", outcome:"rejectedSourceMissing"}.

{
  "tool": "remove_from_context",
  "arguments": {
    "context": "personal:acme",
    "logicalName": "notes/plan.md"
  }
}

Routing worktree files into team content

route_file_to_context

Adopts a worktree file into the team content layer and hides it from git (.git/info/exclude). It is an explicit adopt: CodeSense never does this on its own. Idempotent. Returns an outcome of routed, alreadyRouted, refused, collision, alreadyTracked or notProjectable.

{
  "tool": "route_file_to_context",
  "arguments": {
    "codeRepoPath": "/Users/me/worktrees/app-example",
    "codeRepoSlug": {
      "owner": "acme",
      "repo": "app"
    },
    "logicalName": "notes/plan.md"
  }
}

unroute_file_from_context

The inverse of route_file_to_context: stops managing the file and un-hides it from git. The team copy is deleted only when routing created it and it still holds what was routed; a file that was hydrated, launched or adopted is only unmanaged. Each step is idempotent, so re-running after an interruption completes cleanly.

{
  "tool": "unroute_file_from_context",
  "arguments": {
    "codeRepoPath": "/Users/me/worktrees/app-example",
    "codeRepoSlug": {
      "owner": "acme",
      "repo": "app"
    },
    "logicalName": "notes/plan.md"
  }
}

Context operations

hydrate_worktree, hydrate_story and reverse_sync_worktree run as explicit operations with an operationId.

context_operation_status

Reads the state of one explicit context operation by operationId (a selected request's requestId also works): {operationId, kind, state, target, startedAtMs, finishedAtMs, result}, with state running, ready, failed or cancelled. Read-only.

{
  "tool": "context_operation_status",
  "arguments": {
    "operationId": "<operationId from the operation>"
  }
}

cancel_context_operation

Cancels a running context operation by operationId. A hydrate stops between files locally, or before its Apply on a machine, leaving no partial file; a publish stops before it writes team content. Returns {operationId, cancelling:true} when it was running, else {cancelling:false, state}.

{
  "tool": "cancel_context_operation",
  "arguments": {
    "operationId": "<operationId from the operation>"
  }
}

Sync state and history

get_sync_status

Reads sync status: {setupState, recentOperations, unpublished}. unpublished lists team files changed in the active team's workspaces and not yet back in the team, per workspace and file, with a state such as checked, offline or missing. Local workspaces are counted on every call; pass target:{kind:"remote", machineId, workspaceHandle} to count a machine workspace now. Read-only.

{
  "tool": "get_sync_status",
  "arguments": {}
}

list_hydrated

Lists what CodeSense copied into a workspace, from its managed record. Pass target as {kind:"local", codeRepoPath, sessionId} or {kind:"remote", machineId, workspaceHandle}. Returns hydratedEpics, managedFiles with byOrigin counts and up to 500 files, and the declared context prefixes. Read-only.

{
  "tool": "list_hydrated",
  "arguments": {
    "target": {
      "kind": "local",
      "codeRepoPath": "/Users/me/worktrees/app-example",
      "sessionId": "<your $CODESENSE_TAB_SESSION_ID>"
    }
  }
}

forget_missing_workspace

Removes a machine workspace whose folder is gone from the unsaved-team-edits list. It re-counts first and refuses unless the folder is still missing, and deletes no files, folders or branches on the machine. Take machineId and workspaceHandle from the remote target in get_sync_status. Returns {status:"removed"} or {status:"refused", state, reason}.

{
  "tool": "forget_missing_workspace",
  "arguments": {
    "machineId": "<machineId from list_machines>",
    "workspaceHandle": "<workspaceHandle from get_sync_status>"
  }
}

context_repo_history

Reads the team context repo's history, locally and read-only, newest first and paged. Optional branch (all, main or a branch name), team, paths, limit (default 60, max 500), cursor, and org or sessionId to choose the repo. Returns {commits, nextCursor, openPrs, branches}.

{
  "tool": "context_repo_history",
  "arguments": {
    "branch": "main",
    "limit": 20
  }
}

remove_source_repo

Removes a source repo from a team so the team stops tracking it. When no team in any of your orgs still tracks it, the record binding its local clone is forgotten; the clone stays on disk. Pass org, team and repo. Returns {status:"ok", data:{remoteKey, unboundClone}}.

{
  "tool": "remove_source_repo",
  "arguments": {
    "org": "acme",
    "team": "engineering",
    "repo": "acme/app"
  }
}
