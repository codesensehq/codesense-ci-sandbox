Legacy sense_sync tools

Reference for the five sense_sync_* tools. They are legacy: they belong to the retired automatic projection, and each entry names its current replacement.

How to read this page

There is one content layer left, team content (TeamProjection). For new work use move_content_file, create_content_file, read_content_file, list_hydrated and the publish pair preview_reverse_sync_worktree and reverse_sync_worktree.

Legacy tools

sense_sync_adopt

Legacy. Writes content to logicalName in team content (targetLayer: "TeamProjection", the only layer). Only that team file changes; nothing is copied into a workspace. expectedLayerHash refuses overwriting a team file that changed. To publish edits made in a workspace, prefer preview_reverse_sync_worktree then reverse_sync_worktree.

{
  "tool": "sense_sync_adopt",
  "arguments": {
    "codeRepoPath": "/Users/me/worktrees/app-example",
    "codeRepoSlug": {
      "owner": "acme",
      "repo": "app"
    },
    "logicalName": "notes/plan.md",
    "targetLayer": "TeamProjection",
    "content": "# Plan\n"
  }
}

sense_sync_list_layers

Legacy. Lists the content layers with their writable and backed flags. Today there is one: team content. Read-only.

{
  "tool": "sense_sync_list_layers",
  "arguments": {}
}

sense_sync_move_layer

Legacy. Moves a file between content layers and returns a move outcome. A target that already exists is refused. With one layer left there is rarely a move to make; to rename a team file call move_content_file.

{
  "tool": "sense_sync_move_layer",
  "arguments": {
    "codeRepoPath": "/Users/me/worktrees/app-example",
    "codeRepoSlug": {
      "owner": "acme",
      "repo": "app"
    },
    "fromLayer": "TeamProjection",
    "logicalName": "notes/plan.md",
    "toLayer": "TeamProjection"
  }
}

sense_sync_read_layer_file

Legacy. Reads one team content file's text from a layer. Returns {contentUtf8}, or {error:"binary"} when the bytes are not UTF-8. Read-only. For a current read, use read_content_file.

{
  "tool": "sense_sync_read_layer_file",
  "arguments": {
    "layerId": "TeamProjection",
    "logicalName": "notes/plan.md"
  }
}

sense_sync_read_lockfile

Legacy. Reads the v3 lockfile for (org, team, code_repo), which records what the retired automatic projection wrote; an empty lockfile when none exists. For what CodeSense copied into a workspace now, call list_hydrated. Read-only.

{
  "tool": "sense_sync_read_lockfile",
  "arguments": {
    "codeRepoPath": "/Users/me/worktrees/app-example",
    "codeRepoSlug": {
      "owner": "acme",
      "repo": "app"
    }
  }
}
