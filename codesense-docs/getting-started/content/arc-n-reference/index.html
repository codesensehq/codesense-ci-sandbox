When to reach for Arc N

  • You're authoring an agent.yaml and need to recall whether permissions.claude.default_mode is an alias of defaultMode. → YAML schemas.
  • You pressed a chord that didn't fire and want to see what scope it's bound to. → Keyboard shortcuts.
  • You dropped a .pptx into a workspace and want to know whether CodeSense will preview it or gate as binary. → File extensions.
  • Someone says "worktree" and you want the one-sentence definition plus the arc that teaches it. → Glossary.
  • Something's broken and you don't know where to start. → Troubleshooting index.
  • An update won't install, you want to know what CodeSense sends over the network, or you want to remove it. → Updates, network calls and removing CodeSense.

Versions

Each CodeSense release has a version number, such as 0.1.0. Your version is in Settings → General → About, next to Check for Updates.

Arc N vs. the explorers

CodeSense ships four reference-shaped dashboards at the top of the docs org: schema browser, MCP explorer, primitives explorer, and UI ↔ MCP crossref. Each is a list-detail explorer with a live validator or Try-it button. Arc N is their narrative: short intros that teach you how to read them, plus the lookup tables that don't fit a list-detail shape (shortcuts, extensions, glossary, troubleshooting).

  • Need to validate YAML? → the schema browser has a paste-and-check validator. This arc's YAML schemas page teaches you how to read it.
  • Need every MCP tool? → the MCP explorer. Arc J teaches it.
  • Need every primitive? → the primitives explorer. Arc I teaches it.
