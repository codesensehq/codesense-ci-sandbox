Arc N · Extensions

What CodeSense renders when you click a file.

CodeSense ships twenty viewable file extensions. Markdown and HTML get full editors; .excalidraw opens the canvas; images open inline; everything else lands in the code viewer (CodeMirror 6, read-only, syntax-high­ lighted). Anything unlisted still gets the code viewer as a catch-all, with a binary heuristic that gates known-binary payloads to a placeholder before any read.

Twenty viewable extensions

Grouped by viewer. The markdown and html viewers are the only ones that expose the frontmatter editor; everything else is read-only.

Twenty extensions, five viewers. Everything else falls through to the code viewer as a catch-all, unless the binary heuristic trips first.

The binary fallback

Six extension families short-circuit to a placeholder before any read: archives, executables, fonts, audio/video, office documents, and non-viewable image formats. Clicking the file surfaces its path, size, and a copy button instead of attempting to render.

Known-binary extensions (gated to placeholder)
  • Archives — zip, tar, gz, tgz, bz2, xz, zst, br, 7z, rar
  • Executables — exe, dll, so, dylib, o, a, bin, wasm, class, pyc
  • Fonts — woff, woff2, ttf, otf, eot
  • Audio / video — mp4, webm, mov, avi, mkv, mp3, wav, flac, ogg, m4a
  • Documents — pdf, doc, docx, xls, xlsx, ppt, pptx, sqlite, db
  • Non-viewable images — ico, bmp, tiff, tif, heic

The catch-all code viewer also content-sniffs for binary (NUL check in the first page): an extension-less file that reads as text still opens fine; one that reads as binary falls back to the placeholder.

How to do this via MCP

Ask CodeSense which viewer a path would open in

The resolveViewer bridge verb takes a path (or just an extension) and returns the viewer name without actually opening the file: 

tool_call("resolveViewer", { path: "./notes/incident.pdf" })
// → { ext: "pdf", viewer: null, fallback: "binary-placeholder" }
tool_call("resolveViewer", { path: "./design.excalidraw" })
// → { ext: "excalidraw", viewer: "canvas" }
