Arc N · Shortcuts

Every chord CodeSense fires, grouped by scope.

CodeSense binds 67 keyboard shortcuts across four scopes: global (fire anywhere), team (fire inside a team), workspace (fire with a story workspace focused), and terminal (fire inside the terminal pane). The chord resolves against the smallest matching scope, so a workspace chord wins over the same global one. Rebind anything in Settings → Shortcuts; the table below reflects the ship defaults.

The Toggle Terminal chord is focus-aware: from another view it reveals the existing CLI and focuses it, even when the terminal is already visible; from the CLI itself it hides the terminal. With no workspace open there's nothing to focus, so it hides the terminal. Rebinding keeps the same behavior, and the divider handle still toggles normally.

Rebinding and conflicts

Every entry above is a default. Open Settings → Shortcuts to rebind. When a chord collides with a reserved host chord — the browser's ⌘⇧T "Reopen Closed Tab", for example — CodeSense refuses the override and surfaces the collision inline. Terminal chords honor macCmdOnly: on macOS they fire only with ⌘, never Ctrl, so your shell's ⌃D and friends stay with the PTY. The group labels in the table above tell you which scope each shortcut lives in; narrower scopes shadow wider ones.
