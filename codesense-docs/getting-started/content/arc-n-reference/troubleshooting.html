“Unknown team …” and Inbox failing at launch

If teams disappear or the Inbox fails while many agent sessions reconnect, look for Too many open files (os error 24) or os error 23 in the logs. macOS apps opened from Finder or open can inherit a soft limit of only 256 file descriptors. PTYs, MCP connections, pipes and files share that process budget.

Update CodeSense and restart it when your work is ready. The app, session server and MCP bridge now raise their own soft limit before startup I/O, up to 10,240 or the hard limit, whichever is lower. The startup diagnostic reads open-file limit: soft 256 -> 10240, hard …; macOS may accept a smaller value. Existing higher limits stay higher. Existing server processes need a restart to run the new startup code.

Registry reads briefly retry descriptor exhaustion. If the error persists, release unused sessions and choose Retry in the context-repo load error. You do not need to repair teams.yml for this transient failure. Until you can update, quit CodeSense when ready and start its executable from a shell with ulimit -n 10240 set first; changing a shell's limit does not change an already running app.

Top common issues

Symptom Where to look first Owning arc Quick command
The app stops responding, or an MCP call reports a runtime stall or time limit. See App unresponsive and MCP timeouts for recovery steps, the absolute backstop, and self-capture logs. Arc N list_sessions
An update doesn't install, or you want to remove CodeSense. See Updates, network calls and removing CodeSense. Arc N —
You want to send feedback or report a problem from inside CodeSense. The in-app feedback sender is off in this build. There is no feedback form, and the feedback_send MCP tool refuses every call and sends nothing. Arc N feedback_send
You can't tell which org or team you're in; the switcher looks empty. Open the identity menu at its context repo section (Switch Context Repo). It lists your context repos and ends with Connect a context repo… and Create a new context repo…. The CodeSense docs org is read-only. Arc A ⌘⇧G
A story workspace won't open, or opens blank. Worktree setup failed or hasn't finished. get_sync_status lists each story worktree with setupComplete. Open the story again: a later open reattaches to the worktree. If the repo has no clone on this Mac, see the next row. Arc C get_sync_status
"No local clone attached". The story's repo is in your team, but CodeSense doesn't know where its clone is on this Mac. Choose Attach local clone, then Browse for clone directory or Clone for me. Arc C —
A story doesn't show up, or can't launch. Check its frontmatter: an explicit type (story, bug or spike), a source_repo your team lists, and quotes around any value containing : . Ask an agent to run validate_story on the file. Arc H validate_story
Skills, settings and hooks shipped under {team}/install/ are not being delivered. Your context repo predates the install-tier retirement. Opening the repo folds {team}/install/ into {team}/content/ on load — review the git status deltas and commit them. If conflicts stopped the fold, the manifest error names the retired location and the heal command re-runs ignoring the .folded marker. Arc C heal_install_tree
A worktree shows modified files you never edited. Usually a teammate changed the team copy and this workspace still has the old one. Nothing updates a workspace on its own: call hydrate_worktree for those paths, or preview_reverse_sync_worktree to see what differs. Arc C hydrate_worktree
A terminal is dead, grey, or stuck "reconnecting". PTY lost its host-agent bridge. See Arc D's reconnect flow and the machine column on the terminal tab. Arc D ⌘T new tab
Can't open a terminal on a remote machine. Open Machines and check the machine's state. "Terminal server not installed" offers Install; an out-of-date one offers Update terminal server…. Then use New Terminal On…. Arc D ⌘⇧N picker
An agent says "CodeSense is not running". Its MCP bridge can't reach the app. Open CodeSense. After an app restart the bridge reconnects on its own for about 30 seconds; after that, restart the agent session. Arc E —
Claude Code or Codex isn't offered. CodeSense looks for claude (2.0 or newer) and codex (0.140 or newer). Install or update the CLI. Git 2.44 or newer is the only thing CodeSense needs to start. Arc E —
A page action fails with denied: write budget. The runaway guard stopped a burst of writes from the page. Reload the page; have the page batch fewer writes per click. Arc I —
A routine isn't firing on inbox_idle. Check routine enabled flag, inbox role spelling, and the routines-console dashboard for the last-fired timestamp. Arc G —
A routine fires but the agent never produces output. Agent permissions. Open the agent definition; verify permissions.claude.allow covers the needed verbs. Arc G —
A chord doesn't fire where you expect it to. Scope mismatch. The chord may be bound at a wider scope than where you're pressing it. Arc N shortcuts
A YAML file won't parse; the status spine looks wrong. Paste the file into the schema browser's validator. Arc N validator

When nothing in the table matches

Ask an agent launched from CodeSense to look. The get_sync_status and get_publish_set MCP tools dump CodeSense's view of your story worktrees, context operations and unpublished changes, so an agent (or you) can reason about it directly.
