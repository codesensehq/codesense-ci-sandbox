# Bundled wireframe libraries — attribution & license

CodeSense ships the wireframe packs in this directory as removable, managed
defaults. They are **data CodeSense provisions, not code baked into
the product** — once seeded into a workspace they are plain `.excalidrawlib`
files the user can remove or replace.

## `wireframe-starter.excalidrawlib`

- **Title:** Universal UI kit (22 UI/UX components — buttons, inputs, charts,
  toggles, etc.)
- **Author:** Manuel Ernesto Garcia (<https://github.com/manuelernestog>)
- **Source:** <https://github.com/excalidraw/excalidraw-libraries> →
  `libraries/manuelernestog/universal-ui-kit.excalidrawlib`
- **License:** MIT — the official `excalidraw/excalidraw-libraries` collection
  is published under a root MIT LICENSE that covers the committed
  `.excalidrawlib` files. This is the same MIT basis under which CodeSense
  embeds Excalidraw itself. Permissive for
  redistribution-in-product.
